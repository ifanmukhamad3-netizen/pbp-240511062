# Analisis Komparatif Platform

| Aspek | Web | Desktop | Mobile |
|-------|-----|---------|--------|
| **Bahasa utama** | HTML, CSS, JavaScript, TypeScript | C++, C#, Java, Python | Swift, Kotlin, Java, Dart |
| **Arsitektur** | Client-Server (Browser-based, MVC/MVVM) | Monolithic / Local Client (MVC, MVVM) | Client-Server / Standalone App (MVP, MVVM, Clean Architecture) |
| **Cara distribusi** | Web Host / Server (akses via URL & Browser) | Installer (.exe, .msi, .dmg) atau Application Store | App Store (iOS) & Google Play Store (Android) / APK |
| **Keunggulan** | Akses cepat tanpa instalasi, lintas platform (cross-platform) secara langsung | Performa tinggi, akses penuh ke hardware lokal, bisa berjalan offline | Akses fitur perangkat (GPS, Kamera, Notifikasi Push), portabel |
| **Keterbatasan** | Tergantung koneksi internet & performa browser, akses hardware terbatas | Perlu instalasi/update manual per perangkat, keterbatasan platform OS | Keterbatasan layar/sumber daya, proses review toko aplikasi yang ketat |
| **Contoh aplikasi** | Figma, Web WhatsApp, Google Docs | VS Code, Adobe Photoshop, Spotify Desktop | Instagram, WhatsApp Mobile, Gojek |


# Analisis Perbandingan Platform Web, Desktop, dan Mobile

## 1. Tabel Analisis

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Arsitektur | Client-server, berjalan melalui browser | Aplikasi berjalan langsung pada sistem operasi komputer | Aplikasi berjalan pada sistem operasi smartphone |
| Bahasa Utama | HTML, CSS, JavaScript | Java, Python, C++ | Java, Kotlin, Swift, Dart |
| Distribusi | Diakses melalui URL atau browser | Diinstal melalui file installer atau toko aplikasi | Diinstal melalui Play Store atau App Store |
| Keunggulan | Mudah diakses, tidak perlu instalasi, dan dapat digunakan di berbagai perangkat | Dapat berjalan secara lokal, memiliki akses ke perangkat keras, dan bisa digunakan tanpa internet | Praktis, mudah dibawa, memiliki akses ke kamera, GPS, dan sensor |
| Keterbatasan | Membutuhkan browser dan umumnya koneksi internet untuk layanan online | Perlu instalasi dan menyesuaikan sistem operasi | Memiliki keterbatasan ukuran layar dan kompatibilitas perangkat |
| Contoh Aplikasi | Google Docs, Gmail, dan YouTube | Microsoft Word, Visual Studio Code, dan Notepad | WhatsApp, Instagram, dan Google Maps |

## 2. Kesimpulan

Berdasarkan analisis di atas, platform Web, Desktop, dan Mobile memiliki karakteristik serta keunggulan masing-masing.

- Web: Cocok untuk aplikasi yang membutuhkan akses mudah melalui browser dan berbagai perangkat.
- Desktop: Cocok untuk aplikasi yang membutuhkan performa tinggi serta akses langsung ke sistem operasi komputer.
- Mobile: Cocok untuk aplikasi yang mengutamakan mobilitas, kemudahan penggunaan, dan pemanfaatan fitur smartphone.

Ketiga platform tersebut dapat digunakan sesuai kebutuhan pengembangan aplikasi dan target penggunanya.
